你是一名熟悉 Vue 3、Axios、Express、Multer、PostgreSQL 的全栈开发工程师。

请帮我实现一个“图片上传、按住户 id 和字段命名、保存到服务器硬盘、数据库保存图片路径”的完整功能。

============================================================
一、项目目标
============================================================

前端用户可以上传：

1. 业主头像，字段名为 ownerImg
2. 户型图，字段名为 houseImg

提交时需要完成：

1. 前端获取图片 File 对象
2. 校验图片类型
3. 使用 FormData 发送普通字段和图片文件
4. Express 接收 multipart/form-data
5. Multer 解析上传文件
6. 后端识别图片是 jpg、jpeg 还是 png
7. 根据住户 id 和图片字段生成固定文件名
8. 将图片保存到服务器硬盘
9. 同一个住户重新上传同一类型图片时覆盖旧图片
10. 如果旧图片扩展名不同，也要删除旧扩展名文件
11. PostgreSQL 只保存图片访问路径字符串
12. 查询详情时，前端能够正常回显图片

核心命名规则：

{id}-ownerImg.jpg
{id}-houseImg.jpg

或者：

{id}-ownerImg.png
{id}-houseImg.png

例如住户 id 为 123：

123-ownerImg.jpg
123-houseImg.png

同一个住户重新上传头像时，必须覆盖原头像。
最终每个住户每个图片字段只能对应一个图片文件。

不要使用以下随机文件名作为最终文件名：

ownerImg-时间戳-随机数.png
houseImg-时间戳-随机数.jpg

最终文件名只能包含：

住户 id、图片字段名、jpg 或 png 扩展名。

使用对象保存真实文件：

const selectedFiles = {
  ownerImg: null,
  houseImg: null,
};

说明：

selectedFiles.ownerImg 保存真正的 File 对象。
selectedFiles.houseImg 保存真正的 File 对象。
formData.ownerImg 保存页面预览地址。
formData.houseImg 保存页面预览地址。

实现选择图片：

function handleImageChange(event, field) {
  const [file] = event.target.files;

  if (!file) {
    return;
  }

  const allowedTypes = [
    'image/jpeg',
    'image/png',
  ];

  if (!allowedTypes.includes(file.type)) {
    window.alert('只允许上传 JPG、JPEG 或 PNG 图片');
    event.target.value = '';
    return;
  }

  const previewUrl = URL.createObjectURL(file);

  selectedFiles[field] = file;
  formData[field] = previewUrl;

  event.target.value = '';
}

页面预览：

<img
  v-if="formData.ownerImg"
  :src="formData.ownerImg"
  alt="业主头像"
/>

<img
  v-if="formData.houseImg"
  :src="formData.houseImg"
  alt="户型图"
/>

URL.createObjectURL(file) 只能用于浏览器临时预览，不能保存到数据库。

组件卸载时释放临时 URL：

const objectUrls = new Set();

objectUrls.add(previewUrl);

onBeforeUnmount(() => {
  objectUrls.forEach((url) => {
    URL.revokeObjectURL(url);
  });
});

============================================================
八、Multer 必须使用 memoryStorage
============================================================

不要使用带随机文件名的 diskStorage 作为最终存储方式。

使用 memoryStorage：

const uploadImages = multer({
  storage: multer.memoryStorage(),

  fileFilter: (req, file, callback) => {
    const allowedTypes = [
      'image/jpeg',
      'image/png',
    ];

    if (!allowedTypes.includes(file.mimetype)) {
      callback(
        new Error(
          '只允许上传 JPG、JPEG 或 PNG 图片',
        ),
      );
      return;
    }

    callback(null, true);
  },

  limits: {
    fileSize: 10 * 1024 * 1024,
  },
});

使用 memoryStorage 的原因：

1. 文件先暂存在内存中
2. 后端拿到 req.body.id
3. 后端直接按照最终规则写入目标路径
4. 不会产生 ownerImg-时间戳-随机数这种临时文件
5. 最终硬盘中只出现固定命名的文件

Multer 解析后的文件对象：

req.files.ownerImg[0]
req.files.houseImg[0]

文件内容：

file.buffer

原始文件名：

file.originalname

文件 MIME 类型：

file.mimetype

============================================================
九、识别 JPG、JPEG、PNG
============================================================

不要只通过原始文件名判断扩展名，优先根据 MIME 类型判断：

function getImageExtension(file) {
  if (file.mimetype === 'image/jpeg') {
    return '.jpg';
  }

  if (file.mimetype === 'image/png') {
    return '.png';
  }

  throw new Error(
    '只允许上传 JPG、JPEG 或 PNG 图片',
  );
}

规则：

image/jpeg -> .jpg
image/png  -> .png

即使原始文件名是：

photo.jpeg

最终也统一保存为：

123-ownerImg.jpg

function createSafeId(value) {
  const safeId = String(value || '')
    .replace(/[^a-zA-Z0-9_-]/g, '');

  if (!safeId) {
    throw new Error('住户 id 无效');
  }

  return safeId;
}

============================================================
十一、删除旧图片
============================================================

这是保证同一住户、同一图片字段只保留一张图片的关键。

如果旧文件是：

123-ownerImg.jpg

新文件是：

avatar.png

上传前必须删除：

123-ownerImg.jpg

然后保存：

123-ownerImg.png

实现：

function removeOldImageFiles(
  directory,
  safeId,
  fieldName,
) {
  const prefix = `${safeId}-${fieldName}.`;

  fs.readdirSync(directory)
    .filter((filename) => {
      return filename.startsWith(prefix);
    })
    .forEach((filename) => {
      fs.unlinkSync(
        path.join(directory, filename),
      );
    });
}

删除逻辑必须在写入新图片之前执行。

============================================================
十二、固定文件名和保存文件
============================================================

function saveImageFile(file, id) {
  const safeId = createSafeId(id);
  const extension = getImageExtension(file);
  const fieldName = file.fieldname;

  if (
    fieldName !== 'ownerImg' &&
    fieldName !== 'houseImg'
  ) {
    throw new Error('不支持的图片字段');
  }

  const targetDirectory =
    uploadDirectories[fieldName];

  const filename =
    `${safeId}-${fieldName}${extension}`;

  const targetPath = path.join(
    targetDirectory,
    filename,
  );

  removeOldImageFiles(
    targetDirectory,
    safeId,
    fieldName,
  );

  fs.writeFileSync(
    targetPath,
    file.buffer,
  );

  return filename;
}

固定文件名规则：

{id}-ownerImg.jpg
{id}-ownerImg.png
{id}-houseImg.jpg
{id}-houseImg.png

例如：

123-ownerImg.jpg
123-houseImg.png

不要添加时间戳、随机数或原始中文文件名。

十三、updateInfo 接口
============================================================

接口必须使用 Multer 中间件：

app.post(
  '/api/v1/updateInfo',

  uploadImages.fields([
    {
      name: 'ownerImg',
      maxCount: 1,
    },
    {
      name: 'houseImg',
      maxCount: 1,
    },
  ]),

  async (req, res) => {
    try {
      const {
        id,
        unitId,
        floorNum,
        minHeight,
        maxHeight,
        ownerName,
        idCard,
        phoneNum,
        ownerSex,
        nativePlace,
        ownerImg,
        houseType,
        builtArea,
        orientation,
        propertyType,
        houseImg,
        houseAddress,
      } = req.body;

      if (!id) {
        return res.status(400).json({
          code: 400,
          message: '缺少住户 id',
        });
      }

      const ownerImage =
        req.files?.ownerImg?.[0];

      const houseImage =
        req.files?.houseImg?.[0];

      const ownerImageFilename =
        ownerImage
          ? saveImageFile(ownerImage, id)
          : null;

      const houseImageFilename =
        houseImage
          ? saveImageFile(houseImage, id)
          : null;

      const ownerImagePath =
        ownerImageFilename
          ? `/static/uploads/owner/${ownerImageFilename}`
          : ownerImg || null;

      const houseImagePath =
        houseImageFilename
          ? `/static/uploads/house/${houseImageFilename}`
          : houseImg || null;

      const result = await pool.query(
        `
        UPDATE household
        SET
          unit_id = $1,
          floor_num = $2,
          min_height = $3,
          max_height = $4,
          owner_name = $5,
          id_card = $6,
          phone_num = $7,
          owner_sex = $8,
          native_place = $9,
          owner_img = $10,
          house_type = $11,
          built_area = $12,
          orientation = $13,
          property_type = $14,
          house_img = $15,
          house_address = $16
        WHERE id = $17
        RETURNING
          id,
          owner_name AS "ownerName",
          owner_img AS "ownerImg",
          house_img AS "houseImg",
          house_address AS "houseAddress"
        `,
        [
          unitId,
          floorNum,
          minHeight,
          maxHeight,
          ownerName,
          idCard,
          phoneNum,
          ownerSex,
          nativePlace,
          ownerImagePath,
          houseType,
          builtArea,
          orientation,
          propertyType,
          houseImagePath,
          houseAddress,
          id,
        ],
      );

      return res.json({
        code: 200,
        message: '更新成功',
        data: result.rows[0] || null,
      });
    } catch (error) {
      console.error(
        'updateInfo 失败:',
        error,
      );

      return res.status(500).json({
        code: 500,
        message: error.message,
      });
    }
  },
);

十五、编辑页面图片回显

  "ownerImg": "/static/uploads/owner/123-ownerImg.jpg",
  "houseImg": "/static/uploads/house/123-houseImg.png"

前端拼接完整访问地址：

const apiOrigin = 'http://127.0.0.1:8090';

function getImageUrl(imagePath) {
  if (!imagePath) {
    return imagePath;
  }

  if (
    imagePath.startsWith('http') ||
    imagePath.startsWith('blob:') ||
    imagePath.startsWith('data:')
  ) {
    return imagePath;
  }

  return `${apiOrigin}${
    imagePath.startsWith('/') ? '' : '/'
  }${imagePath}`;
}

使用：

formData.ownerImg =
  getImageUrl(formData.ownerImg);

formData.houseImg =
  getImageUrl(formData.houseImg);

最终浏览器访问：

http://127.0.0.1:8090/static/uploads/owner/123-ownerImg.jpg
